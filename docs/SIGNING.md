# Подпись программы

## Зачем и чего ждать

Подпись Authenticode показывает, **кто** выпустил программу и что файл **не менялся** после
подписания. Сама по себе она не делает программу безопасной и не убирает предупреждение
Windows SmartScreen:

- сертификат EV (расширенная проверка) даёт доверие SmartScreen сразу;
- обычный сертификат OV и сервисы подписи для открытого кода убирают пометку «Неизвестный
  издатель», но репутация копится постепенно, по мере скачиваний;
- **самоподписанный сертификат ничего не даёт другим пользователям**: Windows ему не доверяет.
  Он нужен только чтобы проверить, что сборка и подпись работают.

Пока подписи нет, честный вариант: публиковать вместе с релизом контрольные суммы
(`SHA256SUMS.txt`, делает `tools/package.ps1`) и открытый исходный код.

## Варианты получить настоящую подпись

Условия, цены и доступность меняются, проверьте на сайтах перед выбором.

1. **SignPath Foundation**: бесплатная подпись для открытых проектов, интегрируется с GitHub Actions.
   Нужна заявка и проверка проекта.
2. **Azure Trusted Signing** (сервис Microsoft): платный, подпись из облака без своего сертификата.
   Доступен не всем (ограничения по странам и типу организации).
3. **Сертификат OV/EV от удостоверяющего центра** (DigiCert, Sectigo, SSL.com и др.): платный,
   обычно на год. EV требует аппаратный токен или облачное хранилище ключа.

## Как подписать вручную

```
powershell -File tools\sign.ps1 -Path dist\BadCodeGuard.exe -PfxFile C:\keys\codesign.pfx -PfxPassword ...
```

Скрипт подписывает с SHA-256 и меткой времени (подпись остаётся действительной после окончания
срока сертификата) и проверяет результат. Пароль можно передать через переменную
`BCG_PFX_PASSWORD`, путь к файлу через `BCG_PFX_FILE`. Сертификат из хранилища Windows:
`-Thumbprint <отпечаток>`.

Релиз целиком (сборка, подпись, zip и контрольная сумма):

```
powershell -File tools\package.ps1 -Sign -PfxFile C:\keys\codesign.pfx
```

## Проверка работы подписи без покупки сертификата

```
powershell -File tools\new-dev-cert.ps1                     :: создаёт самоподписанный сертификат
powershell -File tools\sign.ps1 -Path dist\BadCodeGuard.exe -Thumbprint <отпечаток> -AllowUntrusted
powershell -File tools\new-dev-cert.ps1 -Remove             :: удалить сертификат
```

Сертификат создаётся только в вашем личном хранилище, в «Доверенные корневые» ничего не добавляется.

## Подпись в GitHub Actions

Файл `.github/workflows/release.yml` подписывает exe, если в настройках репозитория
(**Settings → Secrets and variables → Actions**) заданы секреты:

| Секрет | Содержимое |
|---|---|
| `BCG_PFX_BASE64` | файл `.pfx` в Base64: `[Convert]::ToBase64String([IO.File]::ReadAllBytes('codesign.pfx'))` |
| `BCG_PFX_PASSWORD` | пароль от `.pfx` |

Без секретов релиз собирается без подписи. Закрытый ключ никогда не кладите в репозиторий:
`.gitignore` исключает `*.pfx`, `*.p12`, `*.key`, но проверяйте сами.

Если используете SignPath или Azure Trusted Signing, замените шаг «Sign» в `release.yml`
на их действие (у каждого свой набор параметров).

## Проверка подписи у пользователя

```
Get-AuthenticodeSignature .\BadCodeGuard.exe | Format-List Status, SignerCertificate
```

Статус `Valid` означает, что подпись целая и ей доверяют; контрольную сумму архива всё равно
стоит сверить с `SHA256SUMS.txt`.
