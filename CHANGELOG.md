# История изменений

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по [SemVer](https://semver.org/lang/ru/).

## [0.3.0]

### Добавлено
- Защита в реальном времени: «Загрузки», «Рабочий стол», `Temp` (только опасные типы файлов), съёмные диски, свои папки. Сторож перезапускает остановившиеся наблюдатели.
- Контроль запуска программ: новая программа проверяется в течение секунды, найденная по базе, правилам или YARA угроза завершается и изолируется.
- Правила YARA (libyara), загрузка набора Yara-Rules по кнопке.
- Проверка архивов: zip, jar, Office (в памяти); 7z, rar, tar, gz, cab, iso и др. через `tar.exe` Windows. Ограничения на размер и вложенность.
- Анализ скриптов, ярлыков, PDF и документов Office.
- Репутация файла по хэшу через VirusTotal (по запросу или автоматически для подозрительных).
- Обновление базы MalwareBazaar и дополнительных списков хэшей, автообновление раз в сутки.
- Журнал находок с экспортом в CSV.
- Плановая проверка (каждый день или раз в неделю).
- Реальный прогресс проверки с оценкой оставшегося времени.
- Защита ключей через Windows DPAPI, журнал работы программы, необязательная защита процесса от остановки.
- Автотесты движка (`tests/engine_tests.cpp`) и интерфейса (`tests/ui_smoke.ps1`).
- Скрипты подписи и упаковки релиза, сборка в GitHub Actions.

### Изменено
- Главная страница показывает состояние каждой защиты; страницы «Главная» и «Настройки» прокручиваются.
- `build.bat` больше не привязан к конкретным путям установки Qt и Visual Studio.

## [0.2.0]
