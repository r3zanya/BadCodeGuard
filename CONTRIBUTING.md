# Участие в разработке

## Сборка и проверка

Нужны Windows 10/11 x64, Visual Studio (рабочая нагрузка «Разработка классических приложений на C++»),
Qt 6.8 или новее для MSVC 2022 64-bit и CMake.

```
build.bat                       :: сборка и dist\BadCodeGuard.exe
set QT_DIR=C:\Qt\6.8.3\msvc2022_64 && build.bat   :: если Qt стоит в другом месте
```

Тесты движка (консольные, без интерфейса):

```
cmake --build build --target bcg_tests
build\bcg_tests.exe
```

Проверка интерфейса (запускает программу, открывает все страницы, делает снимки):

```
powershell -File tests\ui_smoke.ps1 -Exe dist\BadCodeGuard.exe
```

## Правила

- Изменения в `src/engine` и `src/sys` сопровождайте тестами в `tests/engine_tests.cpp`.
- Следуйте стилю соседнего кода: имена, комментарии, плотность комментариев.
- Не добавляйте в репозиторий ключи, сертификаты, чужие базы хэшей и наборы правил
  (Yara-Rules распространяется по GPL-2.0 и скачивается пользователем сам).
- Новые сторонние библиотеки: положите лицензию рядом и добавьте строку в `THIRD_PARTY_NOTICES.md`.
- Один pull request, одна тема.
